Theoretical Pruning Analysis: Pure Backtracking is blind to unassigned variable domain exhaustion; it assigns values sequentially and checks consistency backward only. When an impossible choice is made early, Backtracking explores thousands of failing subtrees before recovering. Forward Checking (FC) looks forward: each assignment immediately eliminates incompatible values from all 20 peer domains. If any peer domain becomes empty ($\emptyset$), the branch is terminated immediately. This cuts backtracks by over 98% across all benchmark puzzle instances.
