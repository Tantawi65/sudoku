AC-3 Arc Consistency Check Verify that the current board reading is constraint-satisfiable
Not run
Why do we need this step? Even if the neural network is 97% accurate overall, one wrong digit can make the board impossible to solve. AC-3 (Arc Consistency Algorithm 3) scans all 810 directed arcs in the binary constraint graph. If two cells in the same row, column, or 3×3 box share the same value, the domain of one collapses to empty (∅) — a mathematical proof that the reading is broken and must be corrected before we can fill in the blank cells.

A* State-Space Search — Minimal-Cost Digit Correction Find the cheapest set of clue substitutions that removes all conflicts
Not run
Why do we need this step? Once AC-3 identifies conflicts, we know the reading is wrong but not which digit(s) to change. We model the correction problem as a state-space search: each state is a set of proposed substitutions, the step cost is the confidence penalty c = max(0, P_top − P_new), and the admissible heuristic sums the minimum correction cost over disjoint conflict pairs (h(n) ≤ h*(n)). A* expands nodes in increasing f(n) = g(n) + h(n) order and is guaranteed to find the minimum-penalty correction without exploring unnecessary branches.
Search formulation
State — set of ((row, col), new_digit) substitutions
Cost — g(n) = ∑ max(0, P_top(cell) − P(new_digit))
Heuristic — h(n) = ∑ min cost over disjoint conflict pairs
Evaluation — f(n) = g(n) + h(n)

CSP Forward Checking — Complete the Puzzle Assign values to all 51 empty cells using backtracking + forward checking + MRV
Not run
Why do we need this step? After A* has fixed any misread clues, we still have ~51 blank cells. Pure backtracking on 951 possibilities is intractable. Forward Checking (FC) shrinks this search drastically: every time we assign a digit to a variable, we immediately remove that digit from the domains of all 20 peer variables. If any peer domain empties we backtrack immediately, rather than discovering the failure much later. The Minimum Remaining Values (MRV) heuristic picks the variable with the fewest legal values next, reducing branching at the most critical points.
